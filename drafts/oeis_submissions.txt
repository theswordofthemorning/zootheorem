SEQUENCE 1 -- merging classes, Collatz (the flagship)
------------------------------------------------------------------
NAME:
Number of residues r in [0, 2^n) such that the trajectories of r and
r+1 under the shortcut Collatz map (x/2 if x even, (3x+1)/2 if x odd)
satisfy T^n(r) = T^n(r+1) and contain the same number of odd terms
among the first n iterates.

25241, 51105, 103358, 208840, 421643, 850737, 1715546, 3457791,
6966495, 14030369, 28247507, 56854178, 114400435, 230136995,
462857658, 930718308, 1871137623, 3761106610, 7558807251,
15188796435, 30516174184

OFFSET: 1,4

COMMENTS:
By Terras's theorem (Acta Arith. 30, 1976) the first n parities of a
trajectory depend only on the residue mod 2^n and T^n(2^n*m + r) =
3^s*m + T^n(r) with s the number of odd steps of r; hence the counted
condition holds for the entire residue class: every pair (2^n*m + r,
2^n*m + r + 1) with m >= 1 in a counted class merges, and both members
have equal total stopping time whenever the merged trajectory reaches
1 (unconditionally true below 2^71, Barina 2025).
a(n+1) >= 2*a(n) for all n (proof: with m = 1 in Terras's identity,
r and r + 2^n both inherit the property). Hence a(n)/2^n is
nondecreasing, and each value is a proven lower bound for the lower
density of pairs of consecutive integers with equal Collatz height:
a(32)/2^32 = 0.435658..., by exact integer computation over all 2^32
residues (no sampling).
The class r = 4 mod 8 (n = 3) is Garner's pair (8k+4, 8k+5) [Garner
1985]; the class r = 5 mod 32 (n = 5) is the family (32m+5, 32m+6) of
Wu and Huang [2001].
The map (3x-1)/2 yields the identical sequence for all n: negation
conjugates the two maps and the reflection r -> 2^n - 1 - r maps one
counted set onto the other (machine-checked proof in Lean 4 at the
link below).

FORMULA:
a(n+1) >= 2*a(n).

EXAMPLE:
a(3) = 1: the residue r = 4 satisfies T^3(4) = T^3(5) = 2 with one
odd step on each side (4 -> 2 -> 1 -> 2 and 5 -> 8 -> 4 -> 2), so the
whole class (8m+4, 8m+5) merges in 3 steps.

PROG:
(Python)
def a(n):
    c = 0
    for r in range(2**n):
        x, y, sx, sy = r, r+1, 0, 0
        for _ in range(n):
            sx += x & 1; sy += y & 1
            x = (3*x+1)//2 if x & 1 else x//2
            y = (3*y+1)//2 if y & 1 else y//2
            if x == y:
                c += sx == sy
                break
    return c

NAME:
Number of residues r in [0, 2^n) such that the trajectories of r and
r+1 under the map x -> x/2 if x even, (5x+1)/2 if x odd, satisfy
T^n(r) = T^n(r+1) and contain the same number of odd terms among the

OFFSET: 1,12

COMMENTS:
The analog of A?????? [SEQUENCE 1] for the 5x+1 map. No convergence
assumption is involved: merging at the same step index with equal odd
count is a finite event decided by the residue class (Terras's
argument uses only the parity structure, valid for every map
(q*x+1)/2 with q odd), so the count is well defined even though 5x+1
trajectories are believed to diverge. The density a(n)/2^n at n = 22
is 0.0044, against 0.409 for the Collatz map: writing the evolution of
the difference of a pair on equal-parity steps as multiplication by
1/2 (both even) or q/2 (both odd), the expected multiplier is
(1+q)/4, which equals 1 only for q = 3 -- among the maps (q*x+1)/2
the Collatz map is the unique critical one, and the collapse of this
density for q = 5 is the supercritical regime.
