%N Number of new Collatz merging classes at level n with exactly 8 mixed-parity steps.
%C Let T be the Collatz map (A014682): T(x) = x/2 if x is even, T(x) = (3*x+1)/2 if x is odd. A new merging class at level n is a residue class modulo 2^n for which the pair (r,r+1) merges at step n with equal odd count and is not inherited from a merging class at level n-1.
%C This sequence counts the new classes whose two trajectories have opposite parity at exactly 8 of the n steps. The first term is for n = 10.
%C The companion sequences for 10 and 12 mixed-parity steps are A398XXX4 and A398XXX5. The lower strata have simple forms: the strata with 2 and 4 mixed-parity steps have one class at each level, and the stratum with 6 mixed-parity steps is 3 + (n-7)*(n-8)/2.

%o def step(x):
%o     return (3*x + 1)//2 if x & 1 else x//2
%o def ok(r, n):
%o     x, y, sx, sy, m = r, r+1, 0, 0, 0
%o     for t in range(1, n+1):
%o         m += ((x ^ y) & 1)
%o         sx += x & 1; sy += y & 1
%o         x, y = step(x), step(y)
%o         if x == y:
%o             return t == n and sx == sy and m == 8
%o     return False
%o def a(n):
%o     return sum(ok(r, n) for r in range(2**n - 1))
