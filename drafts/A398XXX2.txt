%N In the renewal identity for Collatz merging classes, number of reduced h-branch classes at level n.
%C Let T be the Collatz map (A014682): T(x) = x/2 if x is even, T(x) = (3*x+1)/2 if x is odd. Let A(n) be the number of residues r, 0 <= r < 2^n, such that T^n(r) = T^n(r+1) and the first n iterates of r and r+1 contain the same number of odd terms (A398792).
%C For n >= 3 the verified finite identity is A(n+2) = A(n) + (2^n - 1) + G(n) + H(n). This sequence is H(n), the contribution of the branch r == 3 (mod 4).
%C The branch r == 3 (mod 4) reduces after two steps of T to the finite problem for the pair {w, 9*w - 1}; this sequence counts the reduced classes w modulo 2^n that merge within n steps with odd-count difference +2.
